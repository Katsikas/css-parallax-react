# CSS Parallax React Landing Page 

A visual landing page built with React, focusing  on advanced CSS
parallax and scroll-based effects.

At its current stage, the project emphasizes layout, section structure,
and animation-driven design, with minimal JavaScript logic.

## Project Focus

- Fullscreen (100svh) sections
- CSS-driven parallax effects
- Scroll-based transforms using modern CSS
- Clean section-based component architecture


## Tech Stack

- React
- CSS
- Vite
